# BOOR MSI Build Instructions

This repository contains everything needed to build the BOOR MSI installer.

## What is included in the repo

- `BOOR.py` — the Python application to install.
- `build_boor_msi.py` — the builder script that generates the WiX source and references the Python installer.
- `build/BOORInstaller.wxs` — the WiX source file.
- `build/BOOR.py` — copied BOOR source used during package creation.
- `dist/cab1.cab` — generated WiX cabinet file from the build.

## Release assets

The following files are stored in the GitHub release `version 1.0.0`:

- `dist/cab1.cab`
- `python-3.14.5-amd64.exe`

Those two files are required to build the installer successfully.

## Build the MSI

1. Download or copy the release asset `python-3.14.5-amd64.exe` into the repository `build/` folder.
2. Ensure `dist/cab1.cab` is present in `dist/`.
3. Run the build script:

```powershell
python build_boor_msi.py --python-version 3.14.5
```

This generates or updates:

- `build/BOORInstaller.wxs`
- `build/BOOR.py`

4. Build the MSI using WiX Toolset v3.x.

If WiX is installed and on your PATH:

```powershell
python build_boor_msi.py --build
```

If WiX is not on PATH, use the installed WiX bin path directly. Example for WiX v3.14:

```powershell
& 'C:\Program Files (x86)\WiX Toolset v3.14\bin\candle.exe' build\BOORInstaller.wxs -o build\BOORInstaller.wixobj
& 'C:\Program Files (x86)\WiX Toolset v3.14\bin\light.exe' build\BOORInstaller.wixobj -o dist\BOORInstaller.msi
```

## Install the MSI

Run as administrator:

```powershell
msiexec /i .\dist\BOORInstaller.msi /l*v .\dist\boor-install.log
```

## Notes

- `dist/cab1.cab` is generated by WiX during the build process and must remain next to `BOORInstaller.wixobj` while linking.
- The Python installer asset from the release is embedded into the MSI and must be present in `build/` during package creation.
- If you want the easiest way to distribute large binaries, use GitHub Releases rather than committing them directly into the repo.
