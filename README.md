# BOOR Installer

This repository contains the BOOR installer builder and generated WiX installer files.

## Files to publish

- `dist/BOORInstaller.msi` — the generated MSI installer.
- `dist/cab1.cab` — the WiX cabinet file produced during MSI build.
- `build/python-3.14.5-amd64.exe` — the Python installer embedded into the MSI.

## Best way to publish binaries on GitHub

### Option 1: GitHub Releases (recommended)

1. Push your code to GitHub.
2. Open your repository and go to `Releases`.
3. Click `Draft a new release`.
4. Attach `dist/cab1.cab` and `build/python-3.14.5-amd64.exe` as release assets.
5. Publish the release.

This keeps large binaries out of the repo history while still making them available.

### Option 2: Git LFS

If you want to track these files in the repository, use Git Large File Storage.

```powershell
git lfs install
git lfs track "dist/cab1.cab"
git lfs track "build/python-3.14.5-amd64.exe"
git add .gitattributes dist/cab1.cab build/python-3.14.5-amd64.exe
git commit -m "Add WiX CAB and Python installer via Git LFS"
git push origin main
```

> Note: GitHub rejects normal commits with files larger than 100 MB. If the Python installer is larger than that, you must use Git LFS or releases.

## Build instructions

1. Make sure the Python installer is present in `build/`.
2. Run the builder:

```powershell
python build_boor_msi.py --python-version 3.14.5
```

3. If WiX Toolset is installed and on `PATH`, build the MSI:

```powershell
python build_boor_msi.py --build
```

Or build manually with WiX v3.x:

```powershell
"C:\Program Files (x86)\WiX Toolset v3.14\bin\candle.exe" build\BOORInstaller.wxs -o build\BOORInstaller.wixobj
"C:\Program Files (x86)\WiX Toolset v3.14\bin\light.exe" build\BOORInstaller.wixobj -o dist\BOORInstaller.msi
```

## Install the MSI

In an elevated PowerShell window:

```powershell
msiexec /i .\dist\BOORInstaller.msi /l*v .\dist\boor-install.log
```

## Notes

- `dist/cab1.cab` is generated by WiX during the build and does not need to be installed separately.
- `build/python-3.14.5-amd64.exe` is embedded into the installer and must be present during MSI creation.
- If you publish via GitHub release assets, link to the release from this README.
